Meet PawPaw 🐾🐶- A Full-Stack AI-Powered Pet Care Platform

The idea behind PawPaw was to create a single platform where pet parents can manage every aspect of their pets' lives- from health records and appointments to premium services and AI-powered assistance-all through a modern, responsive interface.

 💻 Tech Stack

Frontend
* React.js
* Vite
* React Router DOM
* Context API for state management
* Lucide React Icons
* HTML5, CSS3 & JavaScript (ES6+)

Backend
* Node.js
* Express.js
* RESTful APIs

Database
* SQLite (better-sqlite3)

AI Integration
* OpenAI API powering **Pawla**, the built-in AI assistant

Other Technologies
* Multer (file handling)
* UUID (unique identifiers)
* CORS
* Dotenv
* Nodemon

 ✨ Features

🐾 **Pet Profile Management**

* Add and manage multiple pets
* Store age, breed, gender, weight, favourite food, vaccination details, and microchip information
* Edit and update pet records anytime

📅 **Smart Appointment Booking**

* Schedule appointments through an intuitive booking interface
* Select available time slots
* Add appointment notes
* Manage upcoming appointments
* Cancel appointments whenever required

❤️ **Health Tracking System**

* Vaccination status monitoring
* Health records
* Microchip information
* Meal logging
* Weight and vital tracking
* Easy-to-read health dashboard

🛍️ **Premium Pet Services**

* Browse grooming, boarding, veterinary, daycare, and training services
* Filter services by category
* View service information
* Book services directly through the application

🤖 **Pawla – AI Pet Assistant**
One of the most exciting features of this project.

Pawla is an AI-powered assistant capable of:

* Answering pet care questions
* Providing nutrition recommendations
* Helping owners understand common symptoms
* Sharing behavioural tips
* Guiding first-time pet parents
* Offering emotional support and comforting conversations when pet owners feel stressed or overwhelmed
* Creating a more interactive and human-like user experience.
